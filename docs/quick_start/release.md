# 快速开始——构建版本运行
*Windows系统*

## 1. 下载Release
在Github的Release页面下载最新的构建版本。

## 2. 解压
将下载下来的`*.zip`文件解压到一个目录中。

## 3. 运行
在`server`目录，选择以下任意方式打开终端。
 - 在文件资源管理器地址栏部分输入`cmd`或`powershell`；
 - 右键鼠标，在弹出的菜单中，单击“在终端中打开”（若有）；
 - 按`Shift`键，右键鼠标，在弹出的菜单中，单击“在此处打开Powershell窗口”。

键入`app.exe`，运行应用。
